## ⚡ 1-Click Production Deploy

To compile assets, execute tests, and sync updated files directly to the live server, run:

```bash
php deploy.php
```

Or for instant hotfixes (bypassing test suite):

```bash
php deploy.php --quick
```

---

## 💻 Standard Development Cycle

1. **Modify Local Code**: Make required changes in `app/`, `resources/views/`, `routes/`, etc.
2. **Build Vite Assets**:
   ```bash
   npm run build
   ```
3. **Execute Test Suite**:
   ```bash
   php artisan test
   ```
4. **Git Commit & Push**:
   ```bash
   git add .
   git commit -m "Your feature description"
   git push origin main
   ```
5. **Deploy to Production**:
   ```bash
   php deploy.php
   ```

## ⚙️ Key Artisan Commands

* `php artisan test`: Runs all 16 automated unit & feature tests.
* `php artisan freelancers:recalculate-badges`: Evaluates ratings and earnings, assigning `Top Rated Plus`, `Top Rated`, or `Rising Talent` badges.
* `curl http://workforgemarketplace.gt.tc/cron/recalculate-badges`: Pings the remote production cron endpoint.
